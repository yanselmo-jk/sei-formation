## 🔴 먼저 — 표기 충돌 4건. 이것 때문에 헷갈리는 것이 정상이다

| 충돌 | 구분 |
|---|---|
| `B0` / `B1` **vs** `B-1` / `B-2` / `B-5` | **하이픈 하나 차이.** 앞은 **계산 배치**, 뒤는 **coder 작업 항목**(`HANDOFF_CODER6.md §B`) |
| `C-N` **vs** `B-N` | `C` = **구속조건**(코드가 지켜야 하는 규칙), `B` = **작업 항목**. 서로 대응하지 않는다 |
| `E1/E2/E3` (두 뜻) | ADR-019 = **발견 엔진**(graph 열거 / xTB TS / 반응성 MD) · ADR-015 = **전이성 시험**(blind 재발견 / leave-one-chemistry-out / 사전등록 예측). **`engine-E1` / `test-E1` 로 명시하라**(§0-d) |
| `H-1`…`H-6` **vs** `C-1`…`C-13` | `HANDOFF_CODER8.md` 의 절 번호. `C-` 접두는 구속조건 전용으로 예약됐다 |

🔒 한 문단에 둘이 같이 나오면 **`constraint C-1` / `work item B-2` / `batch B1`** 로 적는다.

## 1. 계산 배치 — B0 / B1

| | 무엇 | 크기 | 상태 |
|---|---|---|---|
| **B0** | **게이트 배치.** 본계산을 시작해도 되는지 판정하는 최소 실험 | 승인 **15,000 reference core-h** | 🟢 **릴리스됨** (ADR-099) |
| **B0-D** | Li⁺Lₙ 용매화 프로브. arm 3개 = 생성 conformer / 이상화 대조군 / r_high | — | arm 1 대칭 판정 대기 |
| **B0-F** | **TS 방법 비교.** 3반응 × 2방법 = 6회, composite 레벨(C-11) | — | 끝단 인증 대기 |
| **B1** | **본배치, 600종.** 🔴 **확정 안 됨** — B0 회신 후 규칙으로 크기가 정해진다 | 상한 67,100 ref core-h (비관) | ⬜ B0 대기 |

**B1 크기 결정 규칙** (STATE:161):
```
N₁ = min(600, 남은예산 / (u_meas × r_comp))
```
`u_meas` 와 `r_comp` 가 **B0 회신에서 나오는 값**이다. ⟹ **B0 없이 B1 을 정할 수 없다.** 그것이 B0 가 "게이트"인 이유.
`B1-D` / `B1-E` / `B1-F` 는 B1 의 하위 항목이다 (B1-D = U-55 측정, 첫 발사 항목).

**정의가 사는 곳**: `05_STATE.md` §0 의 6개 사용자 결정 블록 · `config/b0_species.json` · `config/b0_reactions.json` `[CODE]`

## 6. 측정량과 그 함정

| 기호 | 뜻 | 🔴 주의 |
|---|---|---|
| **κ** (kappa) | 노드 속도 배수. **reference core-h → KNL core-h** 변환 계수. 현재 2.4 | **5개월 일정의 단일 지배 변수.** P6 로만 알 수 있다 |
| **reference core-h** | κ=1 기준 단위. 사용자 승인은 이 단위 (15,000) | 🔴 **`ref-core-h` 라벨이 붙은 값이 실제로는 KNL 이었던 사고**(ADR-095). **단위는 숫자와 같은 칸에** |
| **KNL core-h** | 실제 노드에서 cores × wall_h. 15,000 ref = **36,000 KNL** | 같은 천장의 다른 단위. **올린 게 아니다** |
| **u_cheap** | 값싼 레벨 종당 단가 | 🔴 **층별로 분리. pooled 금지**(ADR-087) |
| **r_composite / r_high** | 레벨 단가비 | 🔴 `1.0365` / `0.3816` 은 **비수렴 위에서 발행된 무효값**(ADR-088). 지금은 `None` |
| **302.4 core-h** | P1 의 실측 비용 | 🔴 **하한이다.** 식별된 편향 3개 중 2개가 낮은 쪽(ADR-096). 중심 추정치로 쓰지 말 것 |

**라벨 규약** `[MEASURED]` / `[ESTIMATE]` / `[LITERATURE]` / **`[UNVERIFIED PROVENANCE]`**(추적 불가) / **`[FIXTURE]`**(테스트용 구성값 — 🔴 **결정의 입력이 될 수 없다**, ADR-098/100)

🔴 **아래 셋은 이미 쓰이고 있었는데 이 표에 올라와 있지 않았다** (`critic9` 지적, 2026-08-20).
라벨 어휘의 공백은 공백으로 남지 않고 **가장 권위 있어 보이는 기존 라벨로 오표기된다** — ADR-098/100 의 교훈이다.

| 라벨 | 뜻 | 출처 |
|---|---|---|
| **`[USER-DOMAIN]`** | 사용자가 자기 전문성으로 제공한 사실. 🟢 결정의 입력이 **될 수 있다**(`[FIXTURE]` 와 다름). 🔴 우리 측정으로 인용 금지, 확인하려고 계산 태우지 말 것. 결과가 이 값과 **충돌하면 평균 내지 말고 RAISE** | ADR-106 |
| **`[MEASURED, FLOOR]`** | 실측이되 **하한**. 중심값으로 인용 금지. 예: P1b 의 `≥944 core-h`(stage 마커 구간만), P1 의 `302.4 core-h`(ADR-096) | ADR-096 / ADR-107 |
| **`[UNRECOVERABLE FROM THIS TREE]`** | 이 아티팩트로는 복원 불가. 🔴 **하한으로 채워 넣지 말 것** — 그 치환이 ADR-098/100 이 말하는 실패다. 어디서 얻을 수 있는지를 함께 적는다 | ADR-107 |
